# Sign-up Form

A responsive sign-up form built with HTML and CSS as part of The Odin Project.

## Features

- Two-column page layout
- Custom background image and Odin logo
- Styled form fields and submit button
- Built-in HTML form validation
- Input focus and invalid-password styling

## Built With

- HTML5
- CSS3
- Flexbox

## Run Locally

1. Clone the repository:
   git clone git@github.com:kshitijtoshniwal/sign-up-form.git

2. Open the project folder.
3. Open `index.html` in your browser.
